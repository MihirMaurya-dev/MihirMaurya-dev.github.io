2. Axion Telemetry Query Deployment Runbook

A. Ingress & NSG Firewall Rules
Allow-SSH-Inbound: TCP 22 → 0.0.0.0/0 (Admin Management)

B. Option 1: Docker Containerized Run (Production)
# Pull image from Docker Hub and run as background daemon
docker pull devopsinsiders/axion-telemetry-query-service:latest
docker run -d --name axion-telemetry -p 8000:8000 \
  -e DATABASE_URL="postgresql://axion:secret@10.0.3.x:5432/axion" \
  devopsinsiders/axion-telemetry-query-service:latest
C. Option 2: Bare-Metal / Systemd Uvicorn Run (Dev)
# Install Python 3.12, venv, and spin up Uvicorn ASGI server
sudo apt update && sudo apt install -y python3-pip python3-venv git
git clone https://github.com/devopsinsiders/axion-telemetry-query-service.git
cd axion-telemetry-query-service
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
D. Healthcheck & Telemetry Verification Probes
